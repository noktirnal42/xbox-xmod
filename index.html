Latest findings

What the lab
already knows.

F2

The USB `$`-override system

Files at the root of an NTFS drive trigger cold-boot operations — Gen9 memory dumps to USB, a build-version oracle, board-level hwinit.cfg overrides. Cataloged with a safe→risky test ladder.

F3

Artifice, dissected

The 2023 devmode privesc chain (junction-based arbitrary read → loose-folder write → sshd key injection → bootsh SYSTEM) is patched on current builds — but its anatomy is the playbook for post-Artifice research.

F4

A 2026 privilege escalation, quietly patched

Firmware tables reveal a SystemOS privilege escalation fixed in July 2026. Details undisclosed — the monitor agent is watching for disclosure.

F5

The next firmware, in hand

All 46 XVD payloads of the upcoming OS build parsed and archived before the console ever takes the update. Retail ODK encryption blocks offline binary diff — an honest blocker, documented as such.

F6

XVD & XBFS, mapped

The container format (AES-XTS, CIK/ODK, signed headers) and boot-flash filesystem (Gen9 offsets, \\.\Xvuc\FlashFs\) verified against tool source and real bytes.

Rules of the lab

Research,
not harm.

  • One target only: the operator's own console on their own LAN. Nothing else is ever scanned or touched.
  • Microsoft cloud is read-only and public: update CDN and documentation. No accounts, no tokens, no Live abuse.
  • No piracy tooling. The goal is homebrew interoperability — nothing here plays unlicensed games.
  • Every console interaction is scripted, reviewed by a human, and reversible. Snapshots before changes.
  • Never fabricate: claims carry citations; the unknown is labeled UNVERIFIED.
